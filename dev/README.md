
# BiblioCom

Sistema de gestão para bibliotecas comunitárias. Estudo de caso da disciplina DPW.

## Como rodar

### Instalação

```bash
npm install
```

### Executar o backend

```bash
npm run dev:api
```

Após iniciar o backend, a documentação da API estará disponível em:

http://localhost:3000/api/docs
